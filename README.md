### 📁 01. FileSense AI – Intelligent File Management System

**Intelligence for Your Files.**

An AI-powered desktop file management application designed to help users search, organize, analyze, and manage files more intelligently.

**Key Features**

- 📊 Intelligent Dashboard – View indexed files, storage usage, file categories, and system insights.
- 🔎 Semantic Search – Search files using natural-language queries and meaning-based search.
- 🤖 AI File Organizer – Organize files into structured groups based on categories or dates.
- 🛡️ Sensitive Data Detection – Identify potentially exposed API keys, passwords, private keys, and other sensitive information.
- ♻️ Duplicate Detection – Find duplicate files.
- 🧠 AI Assistant – AI-oriented chat interface.
- 📂 File Categorization – Group documents, PDFs, images, archives, and other file types.
- ⚙️ Privacy Settings – Configure indexing, semantic search, and privacy-related preferences.

**Tech Stack**

`Python` `PyWebView` `HTML` `CSS` `JavaScript` `Scikit-learn` `psutil`

- 📊 Dashboard with subject progress and task summaries.
- 📖 Add subjects and update completed syllabus topics.
- 📝 Create, complete, and delete tasks with due dates and priorities.
- 📅 Upcoming exam planner with countdowns.
- 🧠 Rule-based study timetable generator.
- ⏱️ Built-in 25-minute focus timer.
